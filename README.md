Chronos Agency: Architects of Time
Chronos Agency is a high-end, minimalist digital agency template designed for consultants, design studios, and strategic partners. The aesthetic focuses on "Precision and Timelessness," utilizing a dark-mode palette, glassmorphism, and high-contrast typography to convey a sense of luxury and elite performance.

🏛️ Design Philosophy
The template is built around the concept of Chronos (Time).

Precision UI: Sharp edges, 1px borders, and surgical use of negative space.

Atmospheric Depth: Subtle radial gradients (Auras) and glassmorphism layers.

Velocity: Fluid scroll-reveal animations and high-performance Tailwind CSS styling.

Brand Accents
The primary accent color is Electric Blue (#3b82f6). To rebrand, search and replace the following Tailwind classes:

text-blue-500

bg-blue-600

border-blue-500

2. Scroll Animations
Animations are handled via the reveal class and an IntersectionObserver script at the bottom of the file. To adjust the "entry" feel:

Change transform: translateY(30px) in the CSS to increase/decrease the slide distance.

Modify transition: all 0.8s ease-out to change the speed of the reveal.

3. Navigation Anchor Links
The navigation uses smooth-scroll anchoring. Ensure any new sections added have a corresponding id that matches the href in the navbar.
